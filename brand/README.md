# BAANZON CHAT Brand Kit — File Index

This package contains a working brand specification and planning assets.

## Included
- `01_Brand_Guidelines/BAANZON_CHAT_Full_Brand_Kit.pdf` — shareable brand specification
- `01_Brand_Guidelines/BAANZON_CHAT_Full_Brand_Kit.docx` — editable brand specification
- `02_Logo_Concept_Studies/` — S3-A and S3-B exploratory SVG concept studies plus comparison CSV
- `03_Colour_System/` — palette JSON, CSV and CSS tokens
- `04_Templates/` — reserved for future approved marketing templates
- `05_Trademark_and_QA/` — validation checklist

## Important status
These are planning and concept-development files. The SVGs are rough exploratory studies, not final or approved production logos. The palette is provisional. No trademark search or legal clearance has been completed. Do not use the concept SVGs as final commercial marks.
